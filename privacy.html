Privacy Policy

Last updated: 31st October 2026

Thoughtful Motivation Uploader is a private tool used only by the owner of the YouTube channel @ThoughtfulMotivation to upload and schedule its own Shorts.

What it accesses

With the channel owner's permission, it uses the YouTube Data API to upload videos to that one channel, set their publish time, and read the channel's own video statistics.

What it stores

An access token, stored only on the owner's computer. It does not collect, store or share data about viewers or any other person, and it is not offered to the public.

Google API Services

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from the Google Account permissions page.
